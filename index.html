Personal Drive Access

Access to the operator's own Google Drive from their own computer, using rclone.

Purpose

This is a personal Google Cloud OAuth application for file storage and management. It supplies OAuth credentials to a locally installed rclone client.

The client can list, read, upload, download, and manage files and folders in the Google Drive account authorized by the operator. It can also present those files through a filesystem mount on the operator's computer. File transfers take place directly between that computer and Google's services.

Authorization and permissions

The operator signs in through Google's OAuth consent screen and grants the client permission to access Google Drive. Broad Drive access is used to manage existing files as well as newly uploaded files. Access can be revoked at any time through Google Account connections.

This site does not offer a public sign-in service. It does not receive Google credentials, OAuth tokens, or the contents of Drive files.

Privacy and contact

The privacy policy explains what the client accesses, where credentials and cached files are kept, and how access can be removed.

For questions, contact the operator through the project's GitHub issues. Issue reports are public; credential or file contents are not needed for support.

Terms of use

This application is intended for the operator's personal use. Google Drive remains subject to Google's terms and the storage account's applicable policies. Rclone is provided under its own license. This personal application is not an official Google or rclone project service.
