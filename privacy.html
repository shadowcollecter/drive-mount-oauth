Personal Drive Access

Privacy Policy

This policy covers Personal Drive Access, a personal OAuth application used with a local rclone client.

Effective date: October 18, 2026

Data accessed

When authorized by the operator, the client accesses Google Drive file and folder metadata, such as names, identifiers, sizes, and modification times, and file contents needed for requested transfers or file operations. The client also uses OAuth access and refresh tokens to authenticate those requests. Basic account information may be used to confirm which Google account is connected.

How data is used

Data is used only to carry out the operator's file storage and management operations, including listing, reading, uploading, downloading, copying, moving, and deleting files, or accessing files through a local mount. Broad Google Drive permission supports management of existing files as well as files created by the client.

The application does not use Google user data for advertising, sale, profiling, or training AI models. Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and protection

OAuth credentials and tokens are stored in a private rclone configuration on the operator's computer. File data may be cached locally to support filesystem access. Local logs and verification reports may contain filenames and operational metadata. These files are protected by local operating-system permissions.

Drive files remain in the operator's Google account until the operator changes or deletes them. This application does not operate a separate backend that stores Drive contents or authentication tokens.

Sharing and transfers

Authentication requests and file operations communicate directly with Google's services. The application does not sell Google user data or send Drive contents or tokens to advertising services, analytics providers, or the rclone project. Sharing a file through Google Drive is controlled by the operator.

Retention and removal

Local cached data is retained according to the operator's rclone configuration. Credentials remain until removed by the operator or revoked. To stop access, stop the local rclone mount or transfer process, revoke the application's access in Google Account connections, and remove its local configuration and cache when they are no longer needed.

Removing this client does not automatically delete files from Google Drive. The operator can manage or delete those files directly in Google Drive.

This website

These static informational pages are hosted by GitHub Pages. They do not include analytics, advertising, sign-in forms, or application cookies. GitHub may process ordinary website request information under its privacy statement. Google's services are governed by Google's privacy policy.

Contact and changes

Contact the operator through the project's GitHub issues. Reports there are public; do not include tokens or private file contents. Changes to this policy will be posted here with an updated effective date.
