# Personal Drive Access

Public application information and privacy policy for a personal rclone OAuth
client. This repository contains only static website files. Credentials, tokens,
private file contents, and transfer logs must not be committed.

- Homepage: https://shadowcollecter.github.io/drive-mount-oauth/
- Privacy: https://shadowcollecter.github.io/drive-mount-oauth/privacy.html
- Terms: https://shadowcollecter.github.io/drive-mount-oauth/#terms

GitHub Pages serves the repository root from the `main` branch.
Pages request search-engine exclusion with `noindex`; the site and repository
remain public. Contact is through this repository's public issue tracker.
